# 📦 Magazzino Bar

Applicazione web leggera e moderna per la gestione dell'inventario e del magazzino di un bar, progettata per essere utilizzata comodamente da qualsiasi dispositivo (smartphone, tablet, PC) tramite browser.

## ✨ Funzionalità Principali

- **Tema Dark:** Interfaccia moderna ed elegante ottimizzata per l'uso su dispositivi mobili.
- **Scansione Codici a Barre:** Utilizzo della fotocamera dello smartphone per la lettura rapida dei codici a barre dei prodotti.
- **Gestione Multi-Magazzino:** Tracciamento separato delle quantità tra il **Magazzino Centrale** e il **Retro-banco**.
- **Controllo Scorte Minime:** Evidenziazione automatica dei prodotti sotto scorta e generazione di una lista d'ordine pronta per essere copiata e incollata su WhatsApp o Email.
- **Esportazione CSV:** Funzione per scaricare l'intero inventario aggiornato in formato tabellare (compatibile con Excel).
- **Database Centralizzato (Cloud):** Sincronizzazione in tempo reale tra più dispositivi grazie all'integrazione con **Supabase**, con un sistema di sicurezza offline tramite `localStorage`.
